# SiamFC Tailgater Robot :)

A 30$ robot designed to tailgate whatever object you select on your PC screen.  

It uses a Siamece Fully Convolutional Network (SiamFC) for real-time object tracking.

This project contains both python scripts for training the network / sending commands to the robot and the C++ ESP32 code to physically drive the robot. It also has a webcam-only script, no robot parts required.
